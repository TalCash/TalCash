# Security

TalCash is in development and has **not launched**: there is no mainnet yet, and no TalCash coin
or token is for sale anywhere. Anyone selling "TalCash" today has nothing to do with this project.

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue: open the repository's
**Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce
it, and what it affects (for example: consensus, the node, the peer-to-peer layer, the wallet).

Especially valuable before launch: anything that lets someone create coins, spend coins they don't
own, split the network, crash or stall nodes, or read a wallet's keys.
